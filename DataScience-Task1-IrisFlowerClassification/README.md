# Iris Flower Classification

## OIBSIP Data Science Task 1

This project focuses on classifying Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models

1. Logistic Regression
2. K-Nearest Neighbors (KNN)

## Best Model

Logistic Regression achieved an accuracy of 93.33%.

## Conclusion

Petal length and petal width are highly useful features for
distinguishing between Iris flower species.
