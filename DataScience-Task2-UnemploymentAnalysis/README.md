**Name:** Karan Dattatray Tormal
**College:** Vivekanand College

## Objective
Exploratory Data Analysis on India's unemployment data to study regional and 
temporal trends, with focus on COVID-19's impact on unemployment rates.

## Dataset
"Unemployment in India" dataset (CMIE / Kaggle - Gokul Rajkumar), 
covering May 2019 - June 2020.

## Key Findings
- Pre-COVID average unemployment: ~9.5%
- Peak during lockdown (Apr-May 2020): ~24%
- States with highest average unemployment: Tripura, Haryana, Jharkhand, Bihar
